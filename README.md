# 蓝片哥 · 国家队观察系统

每个交易日收盘后自动抓取免费公开数据，推断"国家队"（中央汇金、证金、国新、诚通等）当天有没有在ETF上大额买卖，并生成一份网页日报。

数据全部来自 AKShare 封装的免费接口（上交所、深交所、东方财富、财联社），不需要账号或付费数据。

> 这是基于公开数据的**推断工具**，不是官方数据，也不构成投资建议。

---

## 一、安装（只需一次）

在 macOS 终端里：

```bash
cd ~/Projects/national_team_monitor
bash setup.sh            # 建环境、装依赖、回补约一年历史，生成第一份报告（5-10分钟）
bash install_schedule.sh # 设置工作日 18:40 自动运行
```

打开 `reports/latest.html` 就是最新日报；每天的报告也会按日期另存一份。

不联网先看效果：`.venv/bin/python run_daily.py --demo`，报告在 `reports/demo/latest.html`（模拟数据）。

## 二、日常命令

| 命令 | 用途 |
|---|---|
| `.venv/bin/python run_daily.py` | 手动更新一次（收盘后 18:00 以后运行，数据更全） |
| `.venv/bin/python run_daily.py --report-only` | 不联网，只用已有数据重出报告 |
| `.venv/bin/python run_daily.py --quarterly 2026-09-30` | 季报季：抓四大行等重点股前十大流通股东中的国家队席位 |
| `.venv/bin/python run_daily.py --backfill 60` | 漏跑了几周：回补最近60个交易日 |
| `bash install_schedule.sh --remove` | 取消自动运行 |

## 三、系统怎么判断（四层）

**1. 日频·ETF份额（核心）**
ETF份额只能通过申购赎回改变，二级市场买卖不改变份额。所以：
`份额变化 × 收盘价 ≈ 当日申赎金额`。系统盯住国家队历史重仓的13只宽基ETF（沪深300×4、上证50、中证500、中证1000×4、创业板、科创50×2）。

- 每只ETF：用过去60个交易日的**稳健Z分数**（中位数+MAD）判断今天是否异常，|Z| ≥ 2.5 记为异动
- 核心池：净申赎 ≥ 100亿元 且 ≥ 3只同方向异动 → **强烈疑似**；≥ 30亿元 且多只同向 → **疑似**
- 份额拆分/合并会被自动识别剔除，不会误报

**2. 环境层**
沪深300回撤与5日涨跌、两市成交额分位、融资余额分位 → 判定"恐慌区 / 常态 / 过热区"。
恐慌区里大额申购、过热区里大额赎回，最符合国家队的逆周期行为，判定上调一级；反过来则提示"更可能是其他资金"。另外记录"大盘−小盘"涨幅差，用于观察"托大不托小"。

**3. 事件层**
每天扫描全部A股公告和财联社快讯，命中"中央汇金、证金、国新、诚通、平准基金、增持再贷款"等关键词的列入报告。

**4. 季报校准层（倒挂）**
在 `config.py` 里填入国家队上期披露的持有份额（基金季报"前十名持有人"中汇金投资+汇金资管两行相加）。
- 当前总份额 < 披露持有量 → **倒挂**，差额就是确定的最少减持量
- 估算持有 = 披露基数 + 之后各信号日的份额变化（限制在总份额以内）

## 四、需要你定期维护的一件事

`config.py` 里的 `CORE_ETFS` 默认填的是 **2025年底** 的披露数据。2026年上半年国家队已大量赎回，这些基数已经过时。每季度基金季报出来后（1月、4月、7月、10月下旬），把各ETF的汇金持有份额更新为最新一期，倒挂校准才准确。查不到的填 `None`。

## 五、已知局限

- **归因**：份额变化分不清是国家队还是险资等其他大机构，只能说"高度疑似"。
- **噪音变大**：国家队2026年已大幅退出ETF，在这些ETF里的占比远低于2025年，信号的噪音比以前高。
- **深交所份额只给最新值**：深市ETF（1开头）的历史要靠系统每天运行自己积累；上交所可以回溯。东方财富作为补缺。
- **数据时点**：交易所份额数据有时延迟一天发布，系统会在下一次运行时自动补上缺的日期。
- **国新、诚通**更多直接买央企个股，ETF数据里看不太出来，主要靠事件层。
- 免费接口偶尔会改版或限流，失败的步骤会显示在报告底部"数据源状态"里，其他步骤不受影响；长期失败时升级 AKShare：`.venv/bin/python -m pip install -U akshare`。

```
ntm/report.py      HTML日报
ntm/demo.py        模拟数据
data/monitor.db    SQLite数据库（全部原始数据）
data/signals.csv   每日判定结果，可用Excel打开
reports/           每日报告
```
